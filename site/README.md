# Public project page

Static HTML, CSS and a small guide picker. The maintainer hosts it at `/otp-inbox/` on his website; the privacy link refers to that website's separate policy for his personal running instance. It has no backend calls, analytics, signup form, live codes or runtime secrets. Forkers should use their own branding/URLs/privacy policy if hosting a public page.

`assets/otp-orbit.png` is an original ImageGen illustration made for this project. It is a decorative hero asset, not a screenshot or architecture diagram. The text, links and controls are real HTML. Do not represent the illustration as a live inbox.
